# Dominio: Mecanismos de Perfil

## Qué es
El conjunto de componentes, estrategias de ejecución y subproductos que permiten aplicar la entidad Perfil sobre las operaciones de Git en diferentes plataformas.

## Qué no es
No es la implementación final ni el lenguaje de programación en sí, sino el marco donde conviven las betas de experimentación y la solución definitiva.
